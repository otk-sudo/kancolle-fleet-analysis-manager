# 画面デザインの計画

版: v1（2026-10-03）
デザイン案のキャンバス: https://claude.ai/artifact/VW24xQAhzirbp57T96TUGM

実装は段階3（管理画面）と段階5（配信用画面）で行います。この計画は、実装のときに「なぜこの色・文字・配置なのか」を確かめるための資料です。

## 1. 画面ごとの目的

| 画面 | 誰が・どこで見るか | いちばん大事なこと |
|---|---|---|
| 管理画面の応募一覧 | 配信者・関係者が、配信外にPCで見る | 次に誰を分析するかと、確認が必要な応募（重複・条件外）がすぐわかること |
| 配信用画面 | 視聴者が、配信の画面越しに見る。画面は縮小されることも多い | 分析中の提督の目標と相談内容が、離れていても読めること |

管理画面は毎日使う道具なので、飾りよりも読みやすさと間違えにくさを優先します。配信用画面は見せる画面ですが、主役は応募者の情報なので、飾りは最小限にします。

## 2. 色

両方の画面で、次の色だけを使います。補足の文字には灰色（#4A5262）を使います。

| 役割 | 色 | 選んだ理由 |
|---|---|---|
| 地 | 温かみのある白 #FAF7F0 | 辞令や命令書の紙のイメージです。真っ白よりも配信で目が疲れにくくなります |
| 主な文字・強調 | 紺 #14264A | 海軍の制服の紺です。白地との差がはっきりしていて読みやすい色です |
| 区切りの線 | 金 #C9A24B | 制服の金の飾りのイメージです。線にだけ使い、文字には使いません（白地では読みにくいため） |
| 金色の文字 | 濃い金 #8A6A1E | 「前回から変わった」を示すときだけに使います |
| 注意 | 赤茶 #A1251B | 重複・条件外など、確認が必要な印にだけ使います |
| お知らせ | 青 #1F4E9A | 「再応募」の印にだけ使います。注意の赤茶とは明るさも違うので、色の見え方に関係なく区別できます |

紺地に白文字は「その画面でいちばん大事な1か所」にだけ使います。配信用画面では「目標」、管理画面では選んだ応募をまとめて変えるバーです。

艦これのロゴやゲーム内の画像は著作物なので使いません。雰囲気は色だけで出します。

## 3. 文字

- 見出し: しっぽり明朝 B1（Shippori Mincho B1）。公文書のような落ち着きを出すため、画面名と提督名だけに使います
- 本文と数字: BIZ UDPゴシック。ユニバーサルデザインのフォントで、離れて見ても読み間違えにくいからです。XのIDも等幅フォントにせず、この書体でそろえます
- 書体はこの2つだけにします
- 1行は全角40字くらいまでにします（説明文には幅の上限を付けます）
- 強調は文字の大きさと太さで表します。1語だけ色を変えたり、文字の間隔を広げたりする強調はしません

## 4. 構造

- 管理画面の一覧は、ステータスごとのまとまり（分析中、分析予定、未着手）で区切ります。仕様5.4の「次に分析する順」そのものだからです
- 通し番号は振りません。「次の人へ」は印のある未着手の人を飛ばすので、番号と実際の順番がずれてしまうためです。代わりに、次に分析する人に「次に分析」と表示します
- 件数は大きなカードにせず、絞り込みのタブに付けます。押すとその件数の応募に絞り込めるので、件数がそのまま操作になります
- 配信用画面は、左に「目標と相談内容」（いま話していること）、右に「プロフィール」（参考情報）を置きます。プロフィールは行ごとに線で区切った表にし、前回から変わった行には前回の値を並べます

## 5. 動き

- 配信用画面: 分析中の人が変わったときと抽選の結果を出すときに、全体で1回だけ、ふわっと表示します。カードごとにばらばらには動かしません
- 管理画面: 応募を選ぶと操作バーが出る、ドラッグ中の行が持ち上がるなど、操作したときの反応にだけ動きを付けます
- OSで「視差効果を減らす」を設定している人には動かしません（prefers-reduced-motion）

## 6. 言葉

- 画面の言葉は、使う人の言葉で書きます。例: 「未完了」ではなく「これから分析する人」
- ボタンは何が起きるかがわかる言葉にします。例: 「まとめて変更」ではなく「2件を見送りにする」
- エラーは原因と、次にどうすればよいかを書きます。例: 「夕凪 提督の変更を保存できませんでした。ほかの人が先に変更したためです。最新の状態を読み込んでから、もう一度変更してください。」

## 7. 自己批評（汎用テンプレートになっていないか）

最初の案を見直して、次の点を直しました。

| 最初の案 | 問題 | 直したこと |
|---|---|---|
| 件数を5つの大きなカードで表示 | よくある管理画面のテンプレートで、「分析済み（累計）」は一覧を使う目的に関係ありませんでした | 件数を絞り込みのタブに付けました |
| 「順」の列に通し番号 | 実際に分析する順番とずれる | 番号をやめ、ステータスごとの見出しと「次に分析」の表示にしました |
| 配信用画面の「提督」だけ金色 | 1語だけ色を変える安易な強調 | 提督名と同じ紺にし、大きさの差だけにしました |
| 「ただいま分析中」「目標」の文字の間隔を広げていた | 飾りのための強調 | 普通の文字の間隔に戻しました |
| 配信用画面の二重の枠線 | 情報を表さない飾り | なくして、名前と内容の間の金の線1本にしました |
| XのIDだけ等幅フォント | 書体が3つになる | 本文と同じ書体にそろえました |
