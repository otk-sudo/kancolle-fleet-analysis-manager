## 実装するときのお願い

1. **色はCSS変数（デザイントークン）にまとめる。** 画面ごとに色コードを直接書かないでください。

   ```css
   :root {
     --color-ground: #FAF7F0;   /* 地（紙の色） */
     --color-surface: #FFFFFF;  /* カード */
     --color-navy: #14264A;     /* 主な文字・強調 */
     --color-gold: #C9A24B;     /* 区切りの線だけ */
     --color-gold-text: #8A6A1E;/* 「前回から変わった」の文字 */
     --color-text: #1C2330;
     --color-text-sub: #4A5262;
     --color-border: #DCE1EA;
     --color-warn: #A1251B;     /* 重複・条件外・取り消し */
     --color-info: #1F4E9A;     /* 再応募 */
     --radius-card: 10px;
   }
   ```

2. **書体は2つだけ。** 見出しは Shippori Mincho B1、本文は BIZ UDPGothic です（どちらもGoogle Fonts）。XのIDも等幅フォントにしません。
3. **共通の部品にする。** ヘッダー（金の下線）、ステータスの表示、印（重複・条件外・再応募）、カード、「前回から変わった」の金の点。
4. **応募一覧には通し番号を付けない。** ステータスごとの見出し（分析中・分析予定・未着手）で区切り、次に分析する人に「次に分析」と付けます。件数はステータスのタブに出します（design-plan.md の4章）。
5. **配信用画面にボタンや確認を置かない**（仕様7.2）。XのIDと課金額も出しません。
6. **動きは3か所だけ。** 配信用画面の人が切り替わるとき（全体で1回、600ms）、管理画面の操作バーが出るとき、確認のダイアログが開くとき。すべて `prefers-reduced-motion: reduce` のときは止めます。
7. **ボタンとエラーの文言はデザイン案のとおりにする。** ボタンには「2件を見送りにする」のように何が起きるかを書きます。エラーには原因と次にすることを書きます。
8. 押せるものは高さ44px以上にします。操作パネルの「次の人へ」は56pxにして、いちばん目立たせます。
9. 操作パネルはスマホ向けにしません（2026-10-03 どうぺんさんの決定）。PCの別タブで使う前提で、ほかの管理画面と同じ幅・同じ部品で作ります。

## まだ描いていないもの

取り込み画面、設定の「条件ルール・選択肢・ステータス・ユーザー」、削除の確認画面、XのIDの修正、重複の解消。これらは同じ決まり（design-plan.md）で作ってください。迷ったらデザインのスレッドに聞いてください。
