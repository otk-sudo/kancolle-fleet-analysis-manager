# gas/

Googleフォームと、このツールをつなぐための Google Apps Script（GAS）です。

## Google Apps Scriptとは
Googleが無料で提供している、Googleフォームやスプレッドシートに処理を追加できる仕組みです。JavaScriptで書きます。
ここでは「フォームに回答が送信されたら、その内容をこのツールのAPIへ送る」という処理だけを行います。

## 動きの流れ
1. 応募者がGoogleフォームに回答する
2. 「送信時トリガー」で `onFormSubmit` が自動で呼ばれる
3. 質問のタイトルを、APIの項目コードに置き換える（`ITEM_CODES`）
4. 秘密キー（`X-Form-Key`）を付けて、応募受付API（`POST /intake/applications`）に送る

## 設定方法（段階1でAPIが動くようになってから行う）
1. Googleフォームの編集画面で「︙」→「スクリプト エディタ」を開く
2. `Code.gs` の中身を貼り付ける
3. 「プロジェクトの設定」→「スクリプト プロパティ」に `API_URL`、`FORM_KEY`、`FORM_VERSION` を設定する
4. 「トリガー」→「トリガーを追加」で、関数 `onFormSubmit`、イベントの種類「フォーム送信時」を選ぶ

注意: フォームの質問タイトルを変えたら、`ITEM_CODES` のタイトルも同じに直してください。一致しない質問は送られません。
秘密キーはスクリプト プロパティにだけ保存し、このリポジトリには書かないでください。
