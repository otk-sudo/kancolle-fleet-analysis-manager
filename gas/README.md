# gas/

Googleフォームと、このツールをつなぐための Google Apps Script（GAS）です。

## Google Apps Scriptとは
Googleが無料で提供している、Googleフォームやスプレッドシートに処理を追加できる仕組みです。JavaScriptで書きます。
ここでは「フォームに回答が送信されたら、その内容をこのツールのAPIへ送る」ことと、「送れなかった回答をあとで送り直す」ことだけを行います。

## 動きの流れ
1. 応募者がGoogleフォームに回答する
2. 「送信時トリガー」で `onFormSubmit` が自動で呼ばれる
3. 質問のタイトルを、APIの項目コードに置き換える（`ITEM_CODES`）
4. 秘密キー（`X-Form-Key`）を付けて、応募受付API（`POST /intake/applications`）に送る
5. 送れなかったとき（ツールが止まっていた、通信できなかった、など）は「未連携」として覚えておく
6. 運営が、フォームの編集画面のメニュー「応募ツール連携」→「未連携を再送」で送り直す

同じ回答を何度送っても、ツールは回答ID（フォームが回答ごとにつけるID）で見分けて1件だけ登録します。
なので、再送しても二重には登録されません。

## 設定方法（段階4でツールをAWSに公開してから行う）
1. Googleフォームの編集画面で「︙」→「スクリプト エディタ」を開く
2. `Code.gs` の中身を貼り付けて保存する
3. 「プロジェクトの設定」（歯車）→「スクリプト プロパティ」に次の3つを設定する
   - `API_URL`: 応募受付APIのURL（例: `https://api.example.com/intake/applications`）
   - `FORM_KEY`: フォーム用の秘密キー（ツールの運営から受け取る）
   - `FORM_VERSION`: フォームの版（例: `2026-10`。質問を変えたら上げる）
4. 「トリガー」（時計）→「トリガーを追加」で、関数 `onFormSubmit`、イベントのソース「フォームから」、イベントの種類「フォーム送信時」を選んで保存する。初回は Google アカウントの権限の確認が出るので許可する
5. （任意）同じく「トリガーを追加」で、関数 `resendUnsynced`、イベントのソース「時間主導型」、「時間ベースのタイマー」で「1時間おき」を選ぶと、未連携の回答を自動で送り直す
6. フォームの編集画面を開き直すと、上のメニューに「応募ツール連携」が出る

公式の説明:
- トリガー: https://developers.google.com/apps-script/guides/triggers/installable
- フォームの編集画面のメニュー（`FormApp.getUi()`）: https://developers.google.com/apps-script/reference/forms/form-app
- スクリプト プロパティ: https://developers.google.com/apps-script/guides/properties

## メニュー「応募ツール連携」
| 項目 | すること |
|---|---|
| 未連携を確認 | 送れなかった回答の件数と、受付日時・理由を表示する |
| 未連携を再送 | 送れなかった回答をもう一度送る。成功したものは一覧から消える |

理由が `HTTP 400`（入力の誤り。例: XのIDの形が正しくない）の回答は、何度送っても受け付けられません。フォームの回答を確認し、応募者に連絡するなどしてください。
理由が `HTTP 403` なら秘密キー（`FORM_KEY`）が違います。`通信エラー` や `HTTP 5xx` なら、ツール側が直ったあとに再送すれば届きます。

## 未連携の回答の覚え方
スクリプト プロパティに、1件ずつ `UNSYNCED_回答ID` というキーで保存します（中身は受付日時・理由・最後に試した日時）。
スクリプト プロパティは1つの値が最大9KB、全体で最大500KBなので（公式: https://developers.google.com/apps-script/guides/services/quotas ）、1件ずつ別のキーにして、千件以上覚えておけるようにしています。

## 注意
- フォームの質問タイトルを変えたら、`ITEM_CODES` のタイトルも同じに直してください。一致しない質問は送られません
- 秘密キーはスクリプト プロパティにだけ保存し、このリポジトリには書かないでください
- 秘密キーを再発行したら、スクリプト プロパティの `FORM_KEY` を新しい値に書き換えてください
